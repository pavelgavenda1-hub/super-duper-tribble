# World Traveler Stone

A Flutter application for tracking the journey of physical stones with QR codes around the world.

## Features

- 🔐 User authentication with Firebase
- 📱 QR code scanning and generation
- 🗺️ Interactive map showing stone locations
- 📍 GPS tracking and geofencing
- 💎 Diamond reward system
- 📊 Statistics and leaderboards
- 🎡 Wheel of fortune
- 🛍️ E-shop integration

## Project Structure

```
lib/
├── models/          # Data models
├── services/        # API, Firebase, GPS services
├── screens/         # Application screens
├── widgets/         # Reusable components
├── utils/           # Helper functions
└── config/          # Configuration (API keys, constants)
```

## Getting Started

### Prerequisites

- Flutter SDK (>=3.0.0)
- Firebase account
- Google Maps API key

### Installation

1. Clone the repository
2. Run `flutter pub get`
3. Configure Firebase (see Firebase Setup below)
4. Add your Google Maps API key
5. Run `flutter run`
